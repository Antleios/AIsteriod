# 医生端演示数据

本演示数据全部为虚构内容，仅用于界面与业务流程展示，不代表真实患者、诊断或医学结论。

## 创建数据

在 `server/` 目录执行：

```bash
npx prisma migrate deploy
npm run db:seed:demo
```

演示脚本可以重复执行。它只重建下表中固定账号的训练会话，不删除其他用户数据。脚本在 `NODE_ENV=production` 时会拒绝执行。账号、昵称及业务记录不带“演示”或 `demo` 标记，因此页面展示效果与普通账户一致。

默认医生登录信息：

```text
用户名：lin.qinghe
密码：Aisteriod-2026!
```

可以通过 `SAMPLE_ACCOUNT_PASSWORD` 环境变量覆盖所有演示账号的默认密码。

## 停用并清理演示数据

普通题库命令 `npm run db:seed` 不会删除演示数据。它只更新物品命名、表情匹配和颜色连线题库，已经创建的演示账号、训练记录和对话仍会保留。

只删除本项目创建的演示数据时，在 `server/` 目录执行：

```bash
npm run db:seed:demo:clean
```

该命令只匹配 `lin.qinghe` 和下表列出的 8 个固定患者账号，同时兼容清理旧版 `demo.*` 账号。删除账号时，数据库会级联删除它们的登录会话、医患关系、患者资料、训练记录、题目作答、AI 交互、会话摘要和完整对话，不影响其他注册用户和游戏题库。命令可以重复执行，并且在 `NODE_ENV=production` 时会拒绝执行。

清理后如需刷新普通游戏题库，可以单独执行：

```bash
npm run db:seed
```

如果需要清空整个开发数据库（包括非演示账户和所有训练数据），可执行：

```bash
npx prisma migrate reset
```

这是破坏性操作，只适合本地开发数据库。Prisma 会重新应用迁移并自动运行普通 seed；不要在需要保留数据的数据库上执行。

## 命令区别

| 命令 | 用途 | 是否删除现有用户数据 |
| --- | --- | --- |
| `npm run db:seed` | 更新普通游戏题库 | 否 |
| `npm run db:seed:demo` | 创建或刷新固定演示账号及记录 | 只重建固定演示患者的训练数据 |
| `npm run db:seed:demo:clean` | 删除固定演示账号及全部关联数据 | 只删除固定演示账号数据 |
| `npx prisma migrate reset` | 完全重置当前开发数据库 | 是，删除全部数据 |
