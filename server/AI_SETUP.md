# 普通对话、游戏提问与温柔语音

推荐开通阿里云百炼 API 按量付费，用同一地域的 Key 调用两个模型：

| 用途 | 默认模型 | 选择原因 |
| --- | --- | --- |
| 普通对话、游戏提问 | `qwen-plus`，关闭思考模式 | 中文短对话、结构化输出；沿用现有接口 |
| 所有页面的语音播报 | `qwen3-tts-instruct-flash` | 可用自然语言指令控制语速和语气 |

不需要为本项目购买聊天 App 会员或编程套餐。先按量试用和试听，再决定是否购买资源包。

## 配置

本地在 `server/.env` 设置；线上在 Railway 等后端部署平台的 Variables 设置。前端环境变量不要放密钥。本地配置不会同步到线上。

```dotenv
QWEN_API_KEY="在这里填写百炼密钥"
AI_INTERACTION_PROVIDER="qwen"
AI_INTERACTION_PROMPT_VERSION="patient-interaction-v2"
QWEN_CHARACTER_MODEL="qwen-plus"
QWEN_BASE_URL="https://dashscope.aliyuncs.com/compatible-mode/v1"
TTS_PROVIDER="qwen"
QWEN_TTS_MODEL="qwen3-tts-instruct-flash"
QWEN_TTS_VOICE="Cherry"
QWEN_TTS_URL="https://dashscope.aliyuncs.com/api/v1/services/aigc/multimodal-generation/generation"
```

以上 URL 对应中国内地服务。Key 的地域必须和接口地址匹配；其他地域请按百炼控制台和官方文档修改两个 URL。保存后重启后端，并刷新网页。代码已将当前本地普通对话和语音配置改为 `qwen`，填入 Key 即可开始联调。

可选：用 `QWEN_TTS_INSTRUCTIONS` 覆盖默认语气指令，例如“用温柔、自然、耐心的普通话轻声交谈，语速稍慢，停顿自然，音量平稳，不要播音腔、夸张兴奋或刻意装可爱”。默认音色 Cherry，实际音色和语气需填写 Key 后试听。

医生摘要与跨会话记忆的 provider 保持原配置；若也需要模型生成，分别设置 `AI_DOCTOR_PROVIDER=qwen`、`AI_MEMORY_PROVIDER=qwen`，模型默认 `qwen-plus`。这会产生额外调用费用。

## 页面行为

- 用户约 5 秒没有点击、触摸、按键或已开启麦克风中的说话活动时，调用 API 主动鼓励；同一段无操作期间只提醒一次。等待 API、小星播报、切题、页面隐藏和完成游戏时不触发。说话检测依赖浏览器语音识别开启，不会在麦克风关闭时监听环境。
- 同题累计第 2 次明确答错时，后端记录 MULTIPLE_WRONG，前端等当前反馈播报结束后调用 API 安慰。回复写入对话记录并播报，不增加用户发言或作答次数。

- 普通对话调用会话 API，使用后端保存的最近 10 条消息和可用的会话记忆；无 Key 时明确报配置错误，不伪装成真实 AI 回复。
- 三个游戏保留游戏输入区，另一个面板展示本次页面内的题目播报、用户原话、点击或连线作答、对错反馈和 API 对话，换题不会清空记录；刷新或离开页面后，界面记录不保留。颜色连线和表情匹配的输入框默认隐藏，开始录音后显示；有未发送草稿或识别错误时保留，供修改重试。小伙伴气泡显示当前或最近一次播报的完整文字，包括 API 回复。向小星提问不计对错。
- 配置 Qwen 后，物品命名统一由 API 判断当前话语属于作答、聊天还是含糊表达，并生成回复；只有明确作答才计对错。聊天、含糊表达、API 失败或无效返回都不记错，失败时保留输入供重试。离线演示模式仍使用原有规则，不代表完整的自然语言判定能力。
- 物品命名判定从后端题目快照读取标准答案，连同当前话语和最近对话发送给 Qwen；客户端不能提交判定结果。模型判定仍可能出错，投入正式训练前应使用实际表达进行评估。表情匹配和颜色连线的点击、拖动作答继续由规则判分。
- 游戏提问传递 `gameRunId`、`questionId`。后端验证所属患者、游戏与题目，从题目快照生成字数和提示；忽略客户端提供的题目答案。普通游戏提问接口不传私有答案；物品命名判定接口为判断正误会传标准答案，并要求模型在答错、聊天或求提示时不泄露答案。这是提示词约束，并非绝对防泄露保证。
- 游戏自由发言和模型回复沿用 `ConversationTurn`、`AiInteraction` 保存；物品命名判定中的原话与 API 回复保存为 `ConversationTurn`，明确作答另外保存 `GameAttempt`。医生端按现有权限查看。固定游戏话术在实际开始播放时加入页面记录，取消的待播报提示不记入，不逐条写成模型对话。
- 普通对话和三个游戏的所有播报统一使用云端 TTS；未配置、网络失败或浏览器无法播放时回退到较慢、音量较低的本地中文语音，页面显示回退状态。
- 支持 Web Audio 的浏览器默认请求流式 TTS：后端解析 Qwen SSE 音频片段，直接转发 24kHz 单声道 PCM，前端收到片段就排队播放；收到网络结束信号后仍等待最后一段音频播完才切题。浏览器不访问临时云端链接。旧浏览器保留完整 WAV 路径，异常时回退本地语音。更新时需同时更新前后端。
- 固定提示采用后端内存缓存，涵盖程序内预设开场、颜色提示和表情题库反馈。首次合成完成后写入，后续命中直接播放；仅允许名单内固定文本缓存，不缓存患者自由对话。最多 128 条、32 MiB、有效期 24 小时，按模型、音色、语气指令和文本区分，重启后清空。中断或合成失败不会写入缓存。
- 反向代理需允许响应流式传输，不要缓冲 `/api/ai/speech`；接口已设置 `X-Accel-Buffering: no` 和 `Cache-Control: no-store, no-transform`。若线上首音频仍很慢，应检查部署平台是否缓冲响应。
- 可在项目根目录运行 `node --env-file=server/.env server/scripts/check-speech-stream.js` 验证首包及缓存耗时。它会消耗一次固定短句的合成额度，不使用患者数据。当前仍先生成完整对话文本再启动 TTS，本次未改成文本生成流式输出。
- 浏览器限制自动播放时可点击“播放语音”；播放异常会超时解除等待，也可点击“跳过本次语音”。正常情况下游戏在成功语音结束后继续。
- 开始录音时停止播报，避免识别到小星自己的声音。语音识别仍是浏览器 ASR，不是云端实时 ASR，也不是可随时打断的全双工通话。

## 费用参考与隐私

2026-08-31 查询官方页面，中国内地 `qwen-plus` 非思考、输入不超过 128K 档：输入 0.8 元/百万 token，输出 2 元/百万 token。`qwen3-tts-instruct-flash` 为 0.8 元/万计费字符；官方当前规则中一个汉字算 2 个字符。定价、免费额度及区域差异以控制台为准。

- [Qwen Plus 模型与价格](https://help.aliyun.com/zh/model-studio/qwen-plus)
- [百炼模型价格与字符计算](https://help.aliyun.com/zh/model-studio/model-pricing)
- [TTS 请求字段、音色与语气指令](https://help.aliyun.com/en/model-studio/qwen-tts-api)

调用云端模型会发送必要的对话文本和游戏线索；TTS 会发送要朗读的文字并生成有时效的音频链接。不要把真实病历、密码或其他无关个人信息放进提示词。投入真实患者使用前，应明确告知数据用途并确认授权；本应用输出不能替代医生判断。

## 验证

```powershell
# 项目根目录
node --test test/*.test.js
npm run build
npm run lint

# server 目录；独立临时数据库，不修改现有患者库
npm test
```

填入 Key 后，用测试患者账号验证：普通聊天能针对内容回复；游戏问字数与题库一致、提问不扣分；医生端能看见记录；云端语音状态出现且可播放；录音不会拾取播报；断网时输入保留、语音回退清楚可见。无 Key 的自动测试仅模拟上游返回，不能证明真实账户额度、模型权限或音色效果。
